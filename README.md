# goverment_check_project
국회의원 회의록 분석 확인하는 웹사이트


## 📋 현재까지 구현된 기능 요약

### 🏗️ **아키텍처 구조**
- **ETL 파이프라인** 기반의 모듈화된 구조
- **Base 클래스들**: `BaseExtractor`, `BaseTransformer`, `BaseLoader`, `BasePipeline`
- **PostgreSQL** 데이터베이스 연동
- **Qdrant** 벡터 데이터베이스 연동 (RAG 기능)

### **데이터 수집 파이프라인**

#### 1. **국회 일정 → PDF URL 파이프라인** (`ScheduleToPDFPipeline`)
- **Extract**: 국회 일정 API에서 회의 일정 추출
- **Transform**: 일정 데이터에서 날짜 리스트 생성
- **Extract**: 각 날짜별로 PDF URL 추출
- **Transform**: PDF URL 데이터 정리 및 중복 제거
- **Load**: PostgreSQL에 PDF URL 정보 저장

#### 2. **PDF → 발언 텍스트 파이프라인** (`PDFToSpeechPipeline`)
- **Extract**: 미처리 PDF URL 목록 조회 및 병렬 PDF 다운로드
- **Transform**: PDF 텍스트에서 발언자별 발언 추출
- **Load**: 발언자 정보와 발언 내용을 PostgreSQL에 저장

### 🗄️ **데이터베이스 구조**
- **`pdf_url` 테이블**: PDF URL 정보 및 처리 상태
- **`speakers` 테이블**: 발언자 정보
- **`speeches` 테이블**: 발언 내용 및 메타데이터

### 🔍 **RAG (Retrieval-Augmented Generation) 기능**
- **벡터화**: `sentence-transformers/all-MiniLM-L6-v2` 모델 사용
- **벡터 저장**: Qdrant에 발언 내용 임베딩 저장
- **검색 준비**: 발언자, 날짜, 제목 등 메타데이터와 함께 저장

## **완성될 때의 모습**

### 🎯 **핵심 기능**
1. **국회 발언 검색 시스템**
   - 자연어 질의로 관련 발언 검색
   - 발언자별, 안건별, 날짜별 필터링
   - 유사도 기반 관련 발언 추천

2. **의견 분석 대시보드**
   - 실시간 의견 분포 시각화
   - 발언자별 의견 변화 추이
   - 안건별 찬반 비율 분석

3. **AI 기반 인사이트**
   - 발언 내용 요약
   - 핵심 쟁점 추출
   - 의견 대립 지점 분석

### **기술적 완성도**
- **확장성**: 새로운 국회 회기 자동 수집
- **성능**: 대용량 데이터 처리 최적화
- **안정성**: 에러 처리 및 재시도 로직
- **모니터링**: 처리 상태 추적 및 알림

### **사용자 경험**
- **직관적 UI**: 검색과 분석이 쉬운 인터페이스
- **실시간 업데이트**: 새로운 데이터 자동 반영
- **모바일 지원**: 반응형 웹 디자인

### **웹 대시보드** (Streamlit)
- **안건별 발언 분석**: 찬성/반대/중립 의견 분류
- **시각화**: 파이 차트로 의견 분포 표시
- **발언자별 상세 내용**: 발언 내용 미리보기
