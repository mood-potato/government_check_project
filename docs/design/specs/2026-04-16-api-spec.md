**작성일:** 2026-04-16
**수정일:** 2026-04-20

**버전:** v1

---

## 1. 개요

이 문서는 홈 화면과 인물 상세 페이지를 위한 v1 API 계약을 정의한다.

우선 구현할 엔드포인트는 아래 두 개다.

- `GET /api/home`
- `GET /api/members/{member_slug}`

API는 화면 단위 DTO를 반환한다.
단, 고정 카피 / 버튼 URL / 색상 / 검색 옵션처럼 프론트에서 표현 가능한 값은 DTO에서 제외한다.

---

## 2. 공통 규칙

| 항목 | 규칙 |
|---|---|
| Base URL | `/api` |
| 응답 형식 | JSON |
| 날짜 형식 | `YYYY-MM-DD` |
| 외부 식별자 | `slug` |
| 내부 식별자 | `id` |
| 리스트 빈 상태 | `[]` |
| 홈 히어로 빈 상태 | `hero: null` |

에러 응답은 FastAPI 기본 포맷을 따른다.

```json
{
  "detail": "Member not found"
}
```

---

## 3. Endpoint Summary

| Method | Path | 목적 | 성공 응답 |
|---|---|---|---|
| `GET` | `/api/home` | 홈 화면 전체 데이터 | `HomePageDto` |
| `GET` | `/api/members/{member_slug}` | 인물 상세 전체 데이터 | `MemberDetailDto` |

## 5. GET `/api/members/{member_slug}`

```http
GET /api/members/{member_slug}
```

Path parameter:

| 이름 | 타입 | 필수 | 설명 |
|---|---|---|---|
| `member_slug` | string | Y | 인물 URL 식별자 |

예:

```http
GET /api/members/kim-tae-hoon
```

Query parameter 없음.
Request body 없음.

## 6. v1에서 제외한 항목

| 제외 항목 | 이유 |
|---|---|
| 홈 고정 카피 | 프론트 상수로 충분 |
| 버튼 URL | `slug` 기반으로 프론트에서 생성 가능 |
| 검색 scope | 고정 옵션이면 프론트 상수로 충분 |
| 색상 토큰 | 프론트 스타일 매핑으로 충분 |
| pagination | v1 페이지 단위 응답에서는 보류 |
| 분리 엔드포인트 | 실제로 무거워질 때 분리 |
