## 화면 1. 홈 (`/`)

### 목적
서비스 진입점. 검색창과 인기 검색어를 통해 탐색을 시작한다.

### 레이아웃

```
┌─────────────────────────────────────────┐
│  [로고 / 서비스명]                         │
│                                         │
│  ┌─────────────────────────────────┐    │
│  │  🔍 의원 이름 또는 이슈를 검색하세요  │    │
│  └─────────────────────────────────┘    │
│                                         │
│  인기 검색어                              │
│  [기후변화] [최저임금] [교육개혁] [부동산]  │
│  [탄소중립법] [의료개혁] ...              │
│                                         │
│  [의원 목록 바로가기 →]                    │
└─────────────────────────────────────────┘
```

### 컴포넌트 & 데이터

| 컴포넌트 | 데이터 출처 | 표시 내용 |
|---------|-----------|---------|
| 검색창 | - | 텍스트 입력, 엔터/버튼으로 검색 실행 |
| 인기 검색어 | `search_logs` 집계 (최근 7일, 상위 10개) | 검색어 태그, 클릭 시 검색 결과로 이동 |
| 의원 목록 링크 | - | `/members`로 이동 |

### 인터랙션

- 검색창 입력 → 엔터 또는 검색 버튼 클릭 → `/search?q={query}`로 이동
- 인기 검색어 태그 클릭 → `/search?q={tag}`로 이동
- 의원 이름 입력 시 → `/search?q={name}` (의원 탭이 앞에 표시됨)

### 빈 상태

- 인기 검색어 데이터 없음 (초기 서비스) → 인기 검색어 영역 미표시

## 화면 2. 의원 목록 (`/members`)

### 목적
전체 의원을 탐색하고 이슈 태그로 필터링하여 프로필로 진입한다.

### 레이아웃

```
┌─────────────────────────────────────────┐
│  [🔍 검색창]                              │
├─────────────────────────────────────────┤
│  국회의원 목록 (N명)                       │
│                                         │
│  이슈 필터: [전체] [환경] [경제] [교육]     │
│            [복지] [안보] [노동] ...       │
│                                         │
│  정렬: [이름순 ▼] [발언 수순]              │
│                                         │
│  ┌──────┐ ┌──────┐ ┌──────┐            │
│  │ 의원A │ │ 의원B │ │ 의원C │            │
│  │ 위원회│ │ 위원회│ │ 위원회│            │
│  │[환경] │ │[경제] │ │[교육] │            │
│  │[노동] │ │[재정] │ │[복지] │            │
│  └──────┘ └──────┘ └──────┘            │
│                                         │
│  [더 보기] 또는 페이지네이션               │
└─────────────────────────────────────────┘
```

### 컴포넌트 & 데이터

| 컴포넌트 | 데이터 출처 | 표시 내용 |
|---------|-----------|---------|
| 이슈 필터 탭 | `issue_mapping.yaml` 이슈 목록 | 이슈 태그 버튼, 클릭 시 필터 적용 |
| 정렬 선택 | - | 이름순 / 발언 수순 |
| 의원 카드 | `speaker_profiles` + 의원 CSV | 이름, 소속 위원회, 상위 이슈 태그 2개 |
| 페이지네이션 | - | 20명씩 |

### 인터랙션

- 이슈 필터 클릭 → 해당 이슈 태그를 가진 의원만 표시
- 의원 카드 클릭 → `/members/{id}`로 이동
- 정렬 변경 → 목록 재정렬 (페이지 유지)

### 빈 상태

- 이슈 필터 결과 없음 → "해당 이슈의 발언이 있는 의원이 없습니다"

## 화면 3. 의원 프로필 (`/members/{id}`)

### 목적
특정 의원의 발언 이력과 관심 이슈를 한눈에 파악한다.

### 레이아웃

```
┌─────────────────────────────────────────┐
│  [🔍 검색창]                              │
├─────────────────────────────────────────┤
│  ← 의원 목록                              │
│                                         │
│  홍길동                                   │
│  환경노동위원회 · 22대 국회의원              │
│  활동 기간: 2024.05 ~ 현재               │
│                                         │
│  주요 관심 이슈                            │
│  [환경 ●●●●●] [노동 ●●●●] [복지 ●●●]    │
│  [경제 ●●] [교육 ●]                      │
│                                         │
│  위원회별 발언 수                          │
│  [막대 차트: 환경노동위 45건, 본회의 12건]  │
│                                         │
│  발언 목록                                │
│  [이슈 필터: 전체 / 환경 / 노동 / ...]     │
│  ┌───────────────────────────────────┐  │
│  │ 2025.03.15 환경노동위원회           │  │
│  │ "탄소 배출 감소를 위한..."           │  │
│  │ [이슈: 환경] [관련 의안: 탄소중립법] │  │
│  └───────────────────────────────────┘  │
│  ┌───────────────────────────────────┐  │
│  │ 2025.02.10 본회의                  │  │
│  │ "최저임금 인상에 대해..."            │  │
│  └───────────────────────────────────┘  │
│  [더보기]                                │
│                                         │
│  관련 의안                                │
│  · 탄소중립기본법 (2025.01, 처리 중)      │
│  · 최저임금법 개정안 (2024.11, 가결)      │
└─────────────────────────────────────────┘
```

### 컴포넌트 & 데이터

| 컴포넌트 | 데이터 출처 | 표시 내용 |
|---------|-----------|---------|
| 의원 기본 정보 | 의원 CSV + `speaker_profiles` | 이름, 소속 위원회, 활동 기간 |
| 관심 이슈 | `speaker_profiles.top_issues` | 상위 5개 이슈 + 발언 비율 시각화 |
| 위원회별 발언 수 | `speaker_profiles.committee_counts` | 막대 차트 |
| 발언 목록 | `speeches` | 날짜, 회의명, 발언 앞 100자, 이슈 태그, 관련 의안 |
| 이슈 필터 | `speeches.issue_tags` | 이 의원의 발언에 있는 이슈만 표시 |
| 관련 의안 | `bills` + `bill_meetings` | 의안명, 날짜, 처리결과 |

### 인터랙션

- 관심 이슈 태그 클릭 → `/search?q={이슈}` (통합 검색으로 이동)
- 발언 이슈 필터 클릭 → 해당 이슈 발언만 표시
- 발언 클릭 → `/speeches/{id}`로 이동
- 의안 클릭 → `/search?q={의안명}` (통합 검색으로 이동)

### 빈 상태

- 이슈 태그 없음 → "아직 분류된 발언이 없습니다"
- 발언 목록 없음 → "수집된 발언이 없습니다"
- 프로필 미생성 → 스피너 + 실시간 집계 (최초 1회)

## 화면 4. 통합 검색 결과 (`/search?q={query}`)

### 목적
이슈 키워드 또는 의안명으로 관련 의원과 발언을 찾는다.

### 레이아웃

```
┌─────────────────────────────────────────┐
│  [🔍 기후변화              × ]            │
├─────────────────────────────────────────┤
│  "기후변화" 검색 결과                      │
│                                         │
│  [의원 (12명)] [발언 (48건)]              │
│                                         │
│  ── 의원 탭 ──────────────────────────  │
│  ┌───────────────────────────────────┐  │
│  │ 홍길동 · 환경노동위원회              │  │
│  │ 관련 발언 15건                     │  │
│  │ "탄소 배출 감소를 위한 재생에너지..." │  │
│  └───────────────────────────────────┘  │
│  ┌───────────────────────────────────┐  │
│  │ 김철수 · 기획재정위원회              │  │
│  │ 관련 발언 8건                      │  │
│  │ "기후변화 대응을 위한 탄소세..."     │  │
│  └───────────────────────────────────┘  │
│  ...                                    │
│  [1] [2] [3] ...                        │
└─────────────────────────────────────────┘
```

```
│  ── 발언 탭 ──────────────────────────  │
│  ┌───────────────────────────────────┐  │
│  │ 홍길동 · 2025.03.15 환경노동위원회  │  │
│  │ "탄소 배출 감소를 위한 재생에너지   │  │
│  │  투자가 시급합니다..."              │  │
│  │ [이슈: 환경] [의안: 탄소중립법]    │  │
│  └───────────────────────────────────┘  │
```

### 컴포넌트 & 데이터

| 컴포넌트 | 데이터 출처 | 표시 내용 |
|---------|-----------|---------|
| 검색창 | URL 파라미터 `q` | 현재 검색어, 재검색 가능 |
| 결과 탭 | - | 의원 탭 / 발언 탭, 각 건수 표시 |
| 의원 카드 | Qdrant 검색 → 의원별 집계 | 이름, 위원회, 관련 발언 수, 대표 발언 1개 |
| 발언 카드 | Qdrant 검색 결과 | 의원명, 날짜, 회의명, 발언 앞 150자, 이슈 태그 |
| 페이지네이션 | - | 탭별 20건씩 |

### 인터랙션

- 검색창 재입력 → 새 검색 실행
- 탭 전환 → 재검색 실행 (추후 캐싱으로 개선 가능하도록 서비스 레이어 분리)
- 의원 카드 클릭 → `/members/{id}`로 이동
- 발언 카드 클릭 → `/speeches/{id}`로 이동

### 빈 상태 & 예외

| 상황 | 표시 |
|------|------|
| 결과 없음 | "관련 발언을 찾을 수 없습니다. 다른 키워드로 검색해보세요." |
| 결과 50건 초과 | 상위 50건 표시 + "더 구체적인 키워드를 입력하면 더 정확한 결과를 볼 수 있습니다" |
| 2글자 미만 입력 | 검색창 아래 "2글자 이상 입력해주세요" |
| Qdrant 다운 | "검색 서비스가 일시적으로 중단되었습니다. 잠시 후 다시 시도해주세요." |
| 검색 타임아웃 (3초) | "검색에 시간이 걸리고 있습니다. 잠시 후 다시 시도해주세요." |

## 화면 5. 발언 상세 (`/speeches/{id}`)

### 목적
발언 전문과 발언 맥락(앞뒤 발언, 관련 의안)을 확인한다.

### 레이아웃

```
┌─────────────────────────────────────────┐
│  [🔍 검색창]                              │
├─────────────────────────────────────────┤
│  ← 검색 결과로 돌아가기                    │
│                                         │
│  홍길동 · 환경노동위원회                    │
│  2025.03.15  [이슈: 환경] [탄소중립법]    │
│                                         │
│  ┌───────────────────────────────────┐  │
│  │ (발언 전문)                         │  │
│  │ "탄소 배출 감소를 위한 재생에너지    │  │
│  │  투자가 시급합니다. 현재 우리나라의  │  │
│  │  재생에너지 비율은..."              │  │
│  └───────────────────────────────────┘  │
│                                         │
│  같은 회의의 앞뒤 발언                     │
│  ← [이전: 김철수 "탄소세 도입에...]       │
│  → [다음: 박영희 "재생에너지 확대...]      │
│                                         │
│  이 의원의 관련 발언                       │
│  · 2025.01.20 "기후변화 대응 예산..."    │
│  · 2024.11.05 "녹색 전환 정책..."       │
│  · 2024.09.12 "탄소중립 로드맵..."      │
└─────────────────────────────────────────┘
```

### 컴포넌트 & 데이터

| 컴포넌트 | 데이터 출처 | 표시 내용 |
|---------|-----------|---------|
| 발언 헤더 | `speeches` + `speakers` | 의원명, 위원회, 날짜, 이슈 태그, 관련 의안 |
| 발언 전문 | `speeches.speech` | 전체 텍스트 |
| 앞뒤 발언 | `speeches` (같은 pdf_url_id, speech_number ±1) | 이전/다음 발언자 이름 + 발언 앞 50자 |
| 관련 발언 | `speeches` (같은 speaker_id + 같은 issue_tags) | 날짜, 발언 앞 50자, 최대 3건 |

### 인터랙션

- 의원명 클릭 → `/members/{id}`로 이동
- 이슈 태그 클릭 → `/search?q={이슈}`로 이동
- 관련 의안 클릭 → `/search?q={의안명}`으로 이동
- 앞뒤 발언 클릭 → `/speeches/{id}`로 이동
- 관련 발언 클릭 → `/speeches/{id}`로 이동
- 뒤로가기 → 이전 검색 결과 또는 의원 프로필로 복귀

### 빈 상태 & 예외

| 상황 | 표시 |
|------|------|
| 첫 번째 발언 | 이전 발언 링크 없음 |
| 마지막 발언 | 다음 발언 링크 없음 |
| 관련 발언 없음 | 관련 발언 영역 미표시 |
| 존재하지 않는 발언 ID | 404 페이지 |

## 신규 추가 기능 (화면 명세에서 도출)

### 검색어 로깅

| 항목 | 내용 |
|------|------|
| 목적 | 홈 인기 검색어 집계 |
| 저장 시점 | 검색 실행 시 |
| 저장 내용 | 검색어, 검색 시각 |
| 집계 방식 | 최근 7일 기준 검색어별 횟수, 상위 10개 |
| 테이블 | `search_logs (query TEXT, searched_at TIMESTAMP)` |
